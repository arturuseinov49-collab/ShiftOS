# Разработка ShiftOS

1. Установите Node.js 22.14+ и выполните `npm ci`.
2. Создайте ветку `feat/<описание>` или `fix/<описание>`.
3. Для интерфейса начните с `/demo`; ключи для него не нужны.
4. Выполните `npm run check`; для UI дополнительно `npm run test:e2e` после установки Chromium.
5. Откройте PR с описанием поведения, проверок и изменений схемы.

Правила архитектуры описаны в [AGENTS.md](AGENTS.md), схема — в [docs/architecture.md](docs/architecture.md).
Изменение таблицы требует миграции, проверки RLS и `npm run db:types`.
Не добавляйте service-role ключи в приложение и не смешивайте демо с live-данными.

Публичная доступность исходного кода сама по себе не предоставляет лицензию на его использование.
Открытая лицензия пока не выбрана владельцем проекта.
